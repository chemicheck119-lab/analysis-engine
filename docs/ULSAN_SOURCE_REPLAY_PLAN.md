# 울산 공식 원본 재확보와 고정 Resolver 재평가

상태: **설계 완료·구현 전**. 실제 평가 전 고정한 계획이다.

## 목표
사용자가 제공한 공식 ZIP을 최소 열로 투영하고, 현재 고정 Resolver의 2020년 평가와 과거 보고서의 419건/미관측 60건을 비교한다. 모델을 학습하거나 threshold를 바꾸지 않는다.

- 실패 사례: 원본 부재로 419건/60건을 재실행할 수 없고 과거 집계만 남았음.
- 가설: 동일한 기존 전처리·연도 분할을 적용하면 이전 평가 범위를 다시 구성할 수 있음.
- 원본 ZIP SHA-256: `d0ee041579a953084f8037763ac7d0a3d901d11278a6854d348374c69363f976`.
- 현재 고정 artifact: `resolver-char-tfidf-v4-incident-catalog-expanded`, SHA-256 `2696fa7f067163055ff556e5e12ccfa15e7dc08c9ff803838f0db074aa002dff`.
- 과거 2026-08-02 보고서 artifact SHA-256: `e80d612bc3e44bddcb1b4466091a2f45e976e5997774875929e6612669b3f22a`. 현재와 다르므로 과거 모델 byte-identical 재현으로 표현하지 않음.
- 과거 보고서 참고값: 원본 가공 행 1,868, 유효 표현 1,530, 2020년 419사례. Top-1 89.7375%, Top-3 90.2148%, 미관측 표현 60사례의 Top-1 28.3333%.
- 새 데이터: 사용자 제공 ZIP의 공식 CSV 한 개. 신규 사람 라벨/독립 검수는 이번 일정에서 제외.
- 원본 보존: ZIP은 비공개 사본으로 보존. 위치·대응 열을 출력하지 않고 연도/CAS/명칭 6개 열만 private CSV로 투영. 원본 CSV/ZIP/파생/manifest hash를 구분.
- 분할: 기존 2015~2019 source 이력과 2020 test. 반복 표현은 시간 분할의 특성으로 수량을 따로 기록. 미관측 60사례는 신규 secret test가 아니라 이미 알려진 진단 slice.
- 학습·튜닝: 없음. 2020 정답을 alias·threshold·모델 선택에 사용하지 않음.
- 주요 지표: 전체/미관측 표현/미관측 CAS의 Top-1·Top-3·MRR·카탈로그 포함률.
- 안전 지표: 잘못된 단일 exact 후보 건수, hint 안전 회귀. 이 지표는 후보 검색 검사이며 사람 확인이나 현장 안전성이 아님.
- 채택: 안전한 ZIP intake와 재평가 도구가 테스트·CI를 통과하고 계보·분할이 확인되면 평가 도구로 채택. 신규 모델 배포/채택은 하지 않음.
- 불일치: 행 수·분할·지표·hash가 다르면 양쪽 버전과 범위를 함께 보고. 더 그럴듯한 숫자를 선택하거나 결과에 맞게 전처리를 수정하지 않음.
- 중단: ZIP 손상/여러 원본/예상 외 스키마, 모델·ZIP hash 변조, 확인되지 않은 학습 cutoff, 주소 등 원문 로그 유출 위험, 유료 실행 필요.
- 비용: 로컬 CPU·기존 artifact. 신규 서버 임대 0원, GCP/유료 LLM/GPU 호출 없음. 기존 누적 비용은 미확인.
- 주장 가능: 제공된 공식 CSV 범위에서 고정 모델의 후보 검색 성능 및 실패 조건.
- 주장 불가: 현장 안전성·실제 무전 성능·독립 qrel 검증·예전 모델 bytes의 완전 재현·새 모델 성능 개선.

## Retriever 검수 일정 변경
사용자가 독립 검수 시간을 확보할 수 없다고 명시했다. 171개 후보와 1,848쌍을 보존하고 DRAFT를 유지한다.
자동 라벨이나 LLM judge로 사람 승인을 대신하지 않는다. 검색 누락·CAS 일치·기권 정책 같은 기계적 회귀는 계속 가능하지만 관련성 정답 성과와 구분한다.
