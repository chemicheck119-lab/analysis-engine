# 행동 카드 사전 평가 계획 v1

상태: 설계 완료·구현 전. 최초 작성: 2026-09-10, 기준 코드 `21fcdf8`.
결과를 관찰하기 전에 기대 동작을 고정한다. 아래 사례는 사람이 만든 내부 합성 입력이며 실제 신고·무전이나 전문 검수 라벨이 아니다.

## 가설과 채택 조건

기존 모델을 변경하지 않고 결정적 정책과 출처 메타데이터를 연결하면, 확인/보류와 근거 조회 결과를 분리해 반환할 수 있다. 모든 필수 안전 계약 테스트 통과와 실제 artifact 실행을 조건으로 개발용 API를 채택한다. 현장 적용은 채택 범위 밖이다.

병렬화는 동일 입력의 의미 결과가 동일하고 실제 측정이 개선될 때만 속도 개선으로 표현한다. 개선이 없으면 수치와 함께 기각하거나 실행 동시성 선택 기능으로만 남긴다. 절대 응답시간은 사전 보장하지 않는다.

## 고정 시나리오와 기대 동작

| 사례 | 기대 동작 | 검증 방법 |
|---|---|---|
| 정상·미확인 신고 | 후보는 미확인, Rule 실행 없음 | 실제 artifact |
| 잘못 전사된 물질명 | 원문 보존, 자동 확정 없음; 틀린 물질 복구는 주장하지 않음 | 실제 artifact |
| 모호한 표현·미등록 제품 | 질문·보류, 자동 확정 없음 | 실제 artifact + 모호 후보 fixture |
| 부정·추정 | Parser assertion 보존, 사실 승격 없음 | 실제 artifact |
| 시설 이력 없음 | 현재 재고를 만들지 않고 자료 요청 | 실제 artifact |
| CAS 근거 없음 | 출처 없는 대응 참고 금지 | 실제 artifact |
| 한쪽 확인 | 확인 물질 출처만 참고, 조합 잠금 | 실제 artifact |
| 두쪽 확인 | 기존 Gate 통과 후에만 규칙, 전술 승인 없음 | 실제 artifact |
| CAS checksum 오류 | 422, 도구 호출 없음 | API 계약 |
| 미지원 조합 | 보류, 지원 규칙으로 대체하지 않음 | 실제 artifact |
| 다른 CAS 문서 혼입 | 출력 차단·보류 | fault injection |
| 상충 근거·확인 취소·새 증거 | 기존 확인 재사용 제한, 재확인; 의미 상충 완전 탐지 주장 금지 | API 계약 + 실제 artifact |
| 늦은 이전 응답·중복 요청 | 소비자는 revision과 활성 요청으로 폐기/대체, DB 저장 주장 없음 | 참조 소비자 |
| 검색·LLM timeout | 제한시간 후 보류, 후속 작업 차단, 작업 슬롯은 실제 종료까지 점유 | fault injection |
| 출처의 명령문 | 제어 입력으로 실행하지 않고 고정 문구만 사용 | fault injection |
| 동시 요청·연결 취소 | 유한 작업 수, 포화 시 503, 늦은 결과 폐기 | fault injection + HTTP |

## 보고

실제 artifact와 mock 결과를 분리한다. 각 오류 건수의 분모, 첫 카드/최종 결과 p50·p95, 순차/병렬 짝비교, cold/warm 정의, 장비, 입력 길이, 정책·카탈로그·입력·artifact SHA-256과 명령을 기록한다. STT는 이번 API 밖이며 그 시간을 포함한 수치를 만들지 않는다. 작은 내부 표본의 0건은 실제 현장 오류 0건의 증명이 아니다.

## 비용·중단

로컬 CPU와 보유 artifact만 사용한다. 유료 호출/GPU/Cloud 작업 없음. 예상 비용 0원; 누적 계정 비용은 확인되지 않으면 미확인으로 남긴다. 전문적인 전술 문구 승인·새 개인정보·유료 실행·운영 배포가 필요하면 중단하고 요청한다.
