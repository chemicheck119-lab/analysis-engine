# 케미체크119 안전 원칙과 한계

## 1. 반드시 구분할 두 가지

케미체크119는 **운영 환경에 배포할 수 있는 소프트웨어 구조**와 **공개 근거 기반 파일럿
판정**을 함께 제공합니다.

- 인프라: FastAPI, API Key, 읽기 전용 DB, artifact 무결성 검증, Docker·CI 구성
- 충돌 내용: `PUBLIC_SOURCE_PILOT_V1`, `expert_reviewed=false`

전문가 검토 완료를 서비스 실행 조건으로 요구하지는 않습니다. 대신 결과가 공개 원자료 기반
파일럿이라는 사실을 API와 UI에서 숨기지 않습니다.

## 2. 항상 유지할 안전 계약

공개 근거 충돌 결과는 다음 값을 유지해야 합니다.

```text
policy_mode=PUBLIC_SOURCE_PILOT_V1
scope=PUBLIC_SOURCE_CAMEO_SCREENING
expert_reviewed=false
risk_scale.is_probability=false
risk_scale.probability_percent=null
human_confirmation_required=true
final_decision=현장 지휘관 판단
```

이 값이 빠지거나 서로 모순되면 API는 결과를 차단해야 합니다.

## 3. 전문가 검토와 현장 확인은 다릅니다

전문가 검토가 선행조건이 아니어도 **두 현장 확인 게이트**는 필수입니다.

1. 사고물질이 현재 현장에 존재함을 확인
2. 시설물질이 현재 현장에 존재함을 확인
3. 두 확인 레코드의 CAS·역할·근거·시각을 백엔드가 기록
4. 그 뒤에만 Rule Engine 실행

신고문, 음성 전사, Resolver 첫 후보, 과거 업체 이력만으로 Rule Engine을 실행하면 안 됩니다.

## 4. 물질 후보의 한계

Resolver는 이름을 CAS 후보로 연결하는 검색 모델입니다.

- 정확한 이름도 현장 존재를 의미하지 않음
- 하나의 일반명이 여러 CAS를 가질 수 있음
- 제품명·혼합물·농도 표현은 순수물질 CAS 하나로 결정되지 않을 수 있음
- 퍼지 점수는 물질 동일성 확률이 아님
- 등록되지 않은 제품명이나 현장 속칭은 `UNRESOLVED`가 정상일 수 있음
- 문장 안의 별칭은 독립된 원문 span일 때만 exact로 사용
- `염산염` 안의 `염산`, `에탄올성` 안의 `에탄올` 같은 부분 문자열은 CAS 힌트로 사용하지 않음

UI는 후보마다 “현장 확인 필요”를 표시하고, 첫 후보를 자동 선택해 확정하지 않아야 합니다.
부분 문자열 경계 때문에 후보를 보류하는 것은 정상적인 fail-safe 동작입니다. 이 경우 CAS가
없는 일반 근거 검색 결과도 현장 물질 확인을 대체하지 않습니다.

## 5. KOSHA 상세 근거의 한계

현재 통합 물질 카탈로그는 4,300개지만 배포 스냅샷의 상세 KOSHA evidence는 9종입니다.
공식 API 수집기가 있어도 검토·병합·재평가 전에는 지원 범위가 늘어난 것으로 계산하지
않습니다.

- 상세 근거가 없는 CAS에는 `CAS_EVIDENCE_NOT_LOADED`를 반환
- 다른 물질의 문서로 빈칸을 채우지 않음
- 검색 결과의 존재가 최신 MSDS 보장을 의미하지 않음
- 현장 제품의 농도·혼합물·제조사 MSDS를 별도로 확인

UI는 근거가 없을 때 “정보 없음”을 명확히 표시하고 공식 MSDS 확인 링크를 제공해야 합니다.

## 6. 시설 이력의 한계

ICIS·PRTR 시설 결과는 `REPORTED_HANDLING_HISTORY`입니다.

알 수 있는 것:

- 공개 자료에서 과거 업체명·주소와 연결된 물질 후보
- 조사연도와 원자료 링크
- 배출·이동 보고 이력

알 수 없는 것:

- 지금 그 물질이 실제로 있는지
- 현재 보유량과 농도
- 탱크·창고·배수로 위치
- 다른 물질과 실제로 혼합됐는지
- 현재 사고 원인 또는 사고확률

PRTR 배출·이동량을 재고량으로 바꾸거나 결측을 0으로 간주하지 않습니다.

## 7. CAMEO 충돌 스크리닝의 한계

CAMEO 결과는 반응성 그룹 조합에 대한 보수적 스크리닝입니다. 다음 현장 조건을 완전하게
모델링하지 않습니다.

- 농도와 혼합비
- 온도·압력·수분
- 물질의 순도와 제품 첨가제
- 저장 용기 재질
- 누출 속도와 실제 혼합 여부
- 환기, 배수, 지형, 기상
- 반응 시간과 규모

`risk_level_ko=낮음`은 “안전”이 아닙니다. 공개 원자료에 알려진 유해 반응이 없다는
스크리닝 결과일 뿐이며 `SAFE`라는 severity는 사용하지 않습니다.

## 8. 등급은 확률이 아닙니다

CAMEO 원자료 class를 다음 서수 등급으로 표시합니다.

| Raw class | API severity | 화면 표시 | 의미 |
|---:|---|---|---|
| `0` | `NO_KNOWN_HAZARDOUS_REACTION` | 낮음 | 알려진 유해 반응 없음, 안전 보장 아님 |
| `1` | `CAUTION` | 중간 | 주의가 필요한 그룹 조합 |
| `2` | `HIGH_RISK` | 높음 | 가장 보수적으로 높은 그룹 조합 |

금지되는 표현:

- “사고 확률 90%”
- “안전 확률 80%”
- “AI 신뢰도 95%이므로 위험”
- “낮음이므로 보호조치 불필요”

가능한 표현:

- “CAMEO 공개 원자료 기반 서수 등급: 높음”
- “전문가 미검토 공개 근거 파일럿”
- “두 물질과 실제 혼합 여부를 현장에서 확인해야 함”

## 9. 공개 근거 파일럿의 범위

`PUBLIC_SOURCE_PILOT_V1`은 다음을 모두 만족한 crosswalk만 사용합니다.

- 정확한 CAS와 물질 형태를 공식 CAMEO datasheet에서 대조
- 출처 URL이 해당 CAMEO chemical ID와 일치
- 출처 제품·버전·확인 시각 기록
- `PUBLIC_SOURCE_VERIFIED` 상태
- 정책 파일의 허용 조건과 일치

이름만 일치한 `CANDIDATE_UNVERIFIED`는 충돌 스크리닝에 사용하지 않습니다. 프로젝트가 만든
직접 물질쌍 규칙도 이 정책에서는 사용하지 않습니다.

전문가 승인 없이 실행할 수 있다는 말은 근거 없는 규칙도 허용한다는 뜻이 아닙니다.

## 10. 공개 근거 provenance

완료 결과에는 최소 다음이 포함됩니다.

- 사고물질·시설물질 각각의 CAS와 CAMEO ID
- 선택한 CAMEO 물질 형태
- 검증 상태와 방법
- 공식 물질 URL
- 출처 제품과 버전
- 확인 시각
- 사용된 compatibility 출처 URL
- 정책 ID

사용자는 UI의 “대응 근거”에서 이 정보를 확인할 수 있어야 합니다.

## 11. 계획 대응의 한계

`planned_actions`는 사용자가 검토 중이라고 입력한 텍스트입니다. 현재 Rule Engine이 해당
대응을 자동 승인하거나 금지하지 않습니다.

- 체크박스 완료 상태로 해석하지 않음
- 입력했다고 권장 대응이 되는 것이 아님
- 출력의 `UNVALIDATED_ACTION_INPUT` 의미를 유지
- 실제 대응 절차는 현장 SOP와 지휘체계를 우선

## 12. LM Studio와 생성형 AI

LM Studio는 선택적인 신고문 구조화 실험에만 사용합니다. 운영 API에 필수 서비스가 아닙니다.

생성형 모델에 맡기지 않는 값:

- CAS 확정
- 현재 시설 재고
- CAMEO 매핑
- 충돌 raw class와 위험등급
- 대응 허용·금지
- 최종 현장 판단

생성형 요약을 나중에 추가하더라도 구조화된 근거·규칙 결과를 변경할 수 없도록 출력 검증을
적용해야 합니다.

## 13. 개인정보와 운영 로그

신고문에는 이름, 전화번호, 상세 주소와 시설 정보가 포함될 수 있습니다.

- 모델 API 로그에 전체 신고 원문을 남기지 않음
- 응답의 입력 fingerprint와 request ID로 기술 장애 추적
- 사용자 신원과 확인 원본은 서비스 백엔드에서 접근 제어
- 보존 기간과 삭제 정책을 별도로 정의
- API Key, 데이터 bundle URL, manifest trust anchor를 로그에 출력하지 않음
- HTTP query string과 요청·응답 body를 운영 요청 로그에 출력하지 않음

## 14. 실패 시 기본 동작

안전한 기본값은 “추측하지 않고 보류”입니다.

| 조건 | 동작 |
|---|---|
| 물질 미해결 | `UNRESOLVED`, 현장 확인 요청 |
| 동일 이름에 여러 CAS | 복수 후보 유지 |
| CAS 상세 근거 없음 | `CAS_EVIDENCE_NOT_LOADED` |
| 현장 확인 한 건 이하 | Rule 미실행 |
| 공개 검증 crosswalk 없음 | `UNCLASSIFIED` |
| candidate crosswalk | `VERIFY_REQUIRED` |
| CAMEO 그룹 조합 없음 | `UNCLASSIFIED` |
| artifact·정책 무결성 실패 | readiness 실패 |
| 출력 안전 계약 위반 | 응답 차단 |

## 15. UI 필수 표시

충돌 결과 화면에는 다음을 가까운 위치에 표시합니다.

- `공개 근거 파일럿`
- `전문가 검토 안 됨`
- `확률 아님`
- 확인된 사고물질과 시설물질
- 서수 등급 낮음·중간·높음
- 구체적인 제한사항과 현장 확인 항목
- 근거 출처를 펼쳐 볼 수 있는 영역
- `최종 결정: 현장 지휘관 판단`

시설 후보에는 “과거 공개 취급 이력”을 표시하고 현재 보유 물질처럼 표현하지 않습니다.

## 16. 운영 사용 전 조직 차원의 준비

소프트웨어 배포와 별개로 실제 조직에서 사용하려면 다음을 정해야 합니다.

- 누가 현장 확인 레코드를 만들 수 있는지
- 어떤 확인 근거를 허용하는지
- 잘못된 결과를 신고하고 수정하는 절차
- 공개 데이터 갱신 주기
- 장애 시 기존 SOP로 전환하는 절차
- 감사 로그 보존과 개인정보 처리 기준
- 버전 롤백 책임자

이는 전문가 승인 gate와 다른 운영 거버넌스입니다.

## 17. 발표·문서 권장 표현

권장:

> 케미체크119는 현장에서 확인한 두 물질을 NOAA/EPA CAMEO 공개 원자료와 대조해
> 비확률 서수 등급과 근거를 제공하는 의사결정 지원 파일럿입니다.

피해야 할 표현:

> AI가 화학사고 위험 확률을 예측하고 최적 대응을 지시합니다.
