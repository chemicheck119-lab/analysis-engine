# Parser 불확실성 실험 v1 — 결과 관찰 전 계획

기준 코드 `7eda3a8`, 관련 이슈 #62. 상태: **설계 완료·구현 전**.
원문 구간 매칭·문장별 의미 보존을 개선하는 로컬 CPU 실험이다. 신경망 학습은 하지 않는다.

## 관측과 가설

기존 실제 Resolver artifact에서 `염산인 것 같습니다. 아직 확인하지 못했습니다.`는
물질 누락, `염산 미확인`은 NEGATED, 같은 CAS의 부정/긍정 반복은 첫 언급만 남았다.
Parser 전용의 제한된 서술격 어미 허용과 언급 구간별 문맥을 적용하면 이 오류를 줄일 수 있다.
Resolver의 공통 경계·별칭·가중치는 변경하지 않는다.

## 비교와 자료

- A: 기준 코드 Parser + 기존 Resolver bytes.
- B: 제한된 서술격 어미, 문장/절/다른 언급 경계, 반복 언급·미확인 보존.
- 최대 2개 후보(B와 개발 실패 원인을 분리한 B2). 새 가설 없이 반복하지 않는다.
- `parser_uncertainty_cases.py`의 사전 작성 합성 회귀 사례. 라벨은 AI 작성 DRAFT이며 사람 검수·실제 신고 정답이 아니다.
- 같은 템플릿의 물질 치환은 같은 family. family bootstrap을 사용하며 반복·치환을 독립 현장 표본으로 세지 않는다.
- 이번에 작성한 사례는 구현자가 볼 수 있는 개발/설계 회귀셋이지 비공개 테스트가 아니다. 학습·튜닝용 잠금 442건 원문·실패 행 조회는 하지 않는다.
- 전국 공식 사고문 2021~2025년 442건은 관측된 회귀셋으로만 별도 비교한다. 고정 SHA를 검사하고 원문·업체명·주소는 출력하지 않는다.
- 울산 419건 원본은 승인 파일을 찾기 전 재평가 불가. Resolver 파일·코드 bytes가 같다는 것을 419건 실측 비회귀로 바꾸지 않는다.
- 실제 STT의 참조 전사와 가설 전사는 별도 실버 보존 평가 대상. 사람 CAS 정답이 없으면 정답률로 표현하지 않는다.

## 사전 채택 조건

1. 합성 exact 물질 언급 F1이 기준선보다 5%p 이상 개선하고 Precision 비감소.
2. 부정·추정·미확인 assertion 공동 정답률 개선, assertion/역할 처리 각각 기준선 비감소.
3. 미확인을 NEGATED/AFFIRMED로 승격한 사례, 반복 진술 소실의 개발 필수 사례 해결.
4. 사전 정의한 제품명·부분 문자열 음성 대조군 오탐 0건. 원문 밖 생성·CAS 자동확정·확인 전 Rule 실행 0건.
5. 전국 442건 관찰 가능 물질 언급 Recall과 사고유형 지표 비회귀. 이 원천에는 전체 언급·역할·불확실성 정답이 없어 해당 정밀도/역할 성능을 주장하지 않는다.
6. 같은 합성 입력의 warm p95가 기준선의 1.5배 또는 기준선+20ms 중 큰 값을 넘지 않음. 서버 속도 보장이 아님.
7. 기존 테스트·API JSON/SSE·Swagger 계약과 취소/timeout 회귀 통과. 모호한 사람 라벨이 필요한 신경망 실험은 보류.

불충분한 표본의 통계적 일반화나 실무 안전성은 주장하지 않는다. 0건도 이 분모에 한정한다.
모든 조건을 통과해도 개발용 조건부 채택이며 전체 제품은 **부분 구현 또는 개발용 데모**다.
독립 사람 검수·신규 미관측 평가·현장 효과는 **검증되지 않은 가설**로 남긴다.

## 계약과 회귀

원문 그대로, 구간은 Python Unicode code point 기준 start 포함/end 제외. JS UTF-16과 차이를 문서화한다.
`AFFIRMED`는 신고자가 긍정 진술했다는 뜻이지 대원 확인이 아니다. `UNCONFIRMED`를
부재와 구분하고 기존 소비자는 모르는 assertion을 미확인으로 처리한다. 반복 언급은 합치지 않는다.
상충은 위치·시점이 다를 수도 있으므로 자동 화학적 모순 판정 대신 재확인 대상으로 둔다.
행동 카드의 확인 Gate를 완화하지 않는다. 기존 확정 기록과 신고 충돌의 처리는 보수적으로 보류한다.

## 실행·중단·비용

첫 후보 출력 전에 이 계획·합성 사례·기준선 보고서를 고정한다. 결과에는 입력·평가·정책·모델 코드 hash,
artifact hash, 환경·seed·표본 수·실패·latency·명령을 기록한다. 보고서는 기존 경로를 덮어쓰지 않는다.
로컬 CPU 추가 서버 비용 0원, 계정 누적 비용 미확인. 유료 호출·GPU·Cloud·배포·Notion 변경 없음.
전문 라벨·로그인·새 개인정보·유료 작업이 필요하면 해당 경로를 멈추고 요청한다.
