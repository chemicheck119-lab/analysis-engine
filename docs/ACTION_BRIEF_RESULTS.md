# 행동 카드 API 구현·평가 결과

기준일: 2026-09-10. 관련 이슈: [#60](https://github.com/chemicheck119-lab/analysis-engine/issues/60).

## 판정

**개발용 API 조건부 채택**입니다. 실제 artifact를 사용하는 JSON/SSE, 확인·보류 정책, 출처 연결, 인계 구조, Swagger와 재현 명령을 구현했습니다. 전문 검수·현장 사용성·안전성 승인은 완료하지 않았습니다. CI 결과가 확정되기 전에는 최종 완료로 표현하지 않습니다.

| 상태 | 범위 |
|---|---|
| 구현 완료 여부는 CI 판정 참조 | 추가 JSON/SSE API, 카탈로그·정책·확인 취소·출처 검증, 참조 소비자, 로컬 테스트 |
| 부분 구현 또는 개발용 데모 | 현장 대응 지원 전체 서비스, 정보 확인·공식 문서 조회 카드, 역할 분리형 결정적 조율 |
| 설계 완료·구현 전 | 실제 Backend의 revision transaction/영속 저장 연동, 전문 검수 후 전술별 문구 확장 |
| 검증되지 않은 가설 | 소방대원의 판단 시간 단축, 실무 안전성, 현장 무전 일반화, 병렬 실행의 모든 환경에서의 우위 |

## 실제 artifact 평가

환경: Apple M4, 24GiB 메모리, macOS 26.3, Python 3.11.15. 전사문 길이는 보고서에 사례별 기록했습니다. Whisper/STT 시간은 포함하지 않습니다. 모델·DB는 기존 bytes 그대로이며 재학습하지 않았습니다.

- SQLite: `ed81fe9aac45a38880920d967ce8f3954acabfedf7b2f6ea59464552e7958b91`
- Resolver: `2696fa7f067163055ff556e5e12ccfa15e7dc08c9ff803838f0db074aa002dff`
- Retriever: `2e93e066648890400b26f56b532d6ed608b828203f8668e4af3cf63de1bc544b`

예전 preview manifest는 현재 quality policy와 일치하지 않아 첫 로드가 차단됐습니다. 원본을 보존하고 별도 로컬 묶음과 현재 정책 manifest를 만들었습니다. 이 manifest는 배포 품질/독립 검수 부족을 그대로 기록합니다. 무결성 확인을 현장/운영 승인으로 표현하지 않습니다.

`action-brief-v1-r7-final`은 **15종 내부 합성 시나리오 × 2개 실행 모드 × 4회(첫 pass+반복 3회) = 120회**입니다. 기대 HTTP/Rule 호출/확인/출처/문구 계약을 모두 통과했습니다. 정상 응답 112회, 입력 검증 422 응답 8회이며 실제 Rule 호출은 16회입니다. 확인 전 Rule 실행·카드 출처 CAS/역할 불일치의 관측 실패는 0건입니다. 120회 모두 정상 분석이라는 의미는 아닙니다. 정확한 분모·SHA-256은 `data/evaluation/action_brief_v1_summary.json`을 참고하세요.

이 평가는 모델 반환값을 mock으로 대체하지 않았습니다. Rule 호출 수만 원 함수를 감싸 계측했습니다. 한편 입력은 합성이며 실제 신고 정답·전문 라벨이 아닙니다. “15종 통과”는 15명의 사용자 실험도, 15건의 실제 사고도 아닙니다.

### 숨기지 않는 실패와 한계

1. **첫 평가 r1: 120회 중 16회 계약 실패(2종 반복).** 한쪽 확인·취소 후 재분석에서 KOSHA 인덱스의 출처가 URL이 아닌 문자열이어서 대응 참고가 보류됐습니다. 기대 답을 수정하지 않고, 동일 CAS의 검증된 공식 링크를 기존 인덱스에서 보조 조회하도록 수정했습니다. KOSHA 개별 제품 SDS URL을 지어내지는 않았습니다. r2 이후 해당 계약이 통과했습니다.
2. **“염산인 것 같습니다”는 기존 Parser가 물질 표현을 누락했습니다.** 후보 없음·추가 확인으로 남았으며 잘못 확정하지 않았습니다. 안전 계약 통과를 물질 추출 성공으로 세지 않습니다. 이 입력을 정답 라벨로 학습하거나 기존 모델을 바꾸지 않았습니다.
3. **“산성 세척제인지 모르겠습니다”는 실제 artifact에서 복수 CAS가 아니라 후보 없음입니다.** 복수 후보 분기 자체는 별도 fixture로 검증했습니다. 실제 모호표현 일반화 성능을 입증했다고 주장하지 않습니다.
4. 문서 상충 처리는 명시적 상충 보고, 후보/확인 CAS 불일치, 동일 문서·항목의 서로 다른 내용만 감지합니다. 독립 문서 사이의 의미 충돌을 완전히 판단하지 않습니다.
5. 대응 참고는 공식 링크 조회 안내입니다. 제품 SDS·농도·상태·SOP를 검증한 전술 지시가 아닙니다. 전문 검수 문구는 **0건**입니다.

## 순차·병렬 비교

두 모드는 사용자에게 보이는 상태·카드·근거·후보·확인·Rule 결과가 동일한지 함께 검사했습니다. 아래 수치는 기동된 로컬 TestClient JSON 왕복이며 실제 네트워크 SSE와 구분합니다. 각 셀은 warm 정상 응답만 계산합니다.

| 평가 | 모드 순서 | 모드별 표본 | 순차 p50 / p95 | 병렬 p50 / p95 | 해석 |
|---|---|---:|---:|---:|---|
| r3 | 순차→병렬 | 70 | 111.425 / 139.981ms | 107.541 / 158.588ms | 병렬 p95 악화 |
| r4 | 병렬→순차 | 70 | 115.798 / 151.016ms | 106.688 / 118.927ms | 이 표본에서는 개선 |
| r7-final | 순차→병렬 | 42 | 115.888 / 140.522ms | 108.074 / 119.109ms | 이 표본에서는 개선 |

따라서 **기본은 순차 유지**, 병렬은 환경별 비교 옵션으로 남겼습니다. 일부 개선 회차만 골라 항상 더 빠르다고 주장하지 않습니다. 독립 프로세스 cold start/OS cold cache 실험이나 사용자 A/B 테스트가 아닙니다.

## 순차 출력·장애·문서 검사

실제 loopback HTTP 30회에서 initial/final 수신 순서와 snapshot 교체를 검사했습니다. 첫 카드 p50 **38.688ms**, p95 **45.120ms**; 최종 결과 p50 **118.596ms**, p95 **119.774ms**입니다. 38자 합성 입력, 서버 기동 이후의 수치이고 STT·WAN·Cloud 시간은 없습니다. 첫 카드는 즉시 표시 가능한 확인·보류 안내이며 전체 분석 완료가 아닙니다.

새 단위·계약 테스트는 실제 artifact 평가와 별도입니다. 다른 CAS 문서, 출처 명령문, 명시적 상충, 취소, 늦은 응답, 같은 revision의 새 요청, 중복 이벤트, API 키, checksum, 고정 문구, LLM 미사용, 로그 원문 비노출 등을 검사합니다. `test_action_brief_http.py`는 실제 소켓 서버에 검색 지연을 주입하여 연결 종료·2개 동시 요청·503·timeout·작업 정리 후 복구를 검사합니다. 실제 현장 장애 통계가 아닙니다.

- 로컬 전체 검사: **590 tests passed**, Ruff check/format, OpenAPI drift 통과. 새 행동 카드 관련 검사는 37개입니다.
- Swagger: 브라우저에서 Authorize → Try it out → Execute 후 실제 `200`, `NEEDS_CONFIRMATION`, Rule 미실행 응답 확인.
- API 키 보안 스키마와 JSON 요청·응답 예시 검증. SSE는 별도 HTTP 클라이언트 검증.
- 로컬 Docker 엔진 미기동으로 로컬 이미지 빌드는 미실행. GitHub CI 결과로 별도 확인합니다.
- 기존 Resolver 419건/Parser 442건/STT/DRAFT Retriever 점수는 다시 측정하거나 합치지 않았습니다.
