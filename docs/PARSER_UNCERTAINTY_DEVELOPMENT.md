기준선 합성 47건, 기대 언급 44개: TP 28/FN 16/FP 0, assertion 공동 정답 21/44.

## B

원문 구간·서술격 어미·미확인 분리를 구현한 후보는 언급 44/44를 회복했다.
다만 `염산은 없으며, 질산이 누출됩니다.`에서 첫 부정을 AFFIRMED로 잘못 분류했다.
이는 부정 어미 `으며`를 절 경계에서 제거해 문맥이 `은 없`으로 잘렸기 때문이다.
B의 지표 게이트 통과만으로 이 관측 실패를 숨기거나 채택하지 않는다.

## B2 진입 이유 — 후보 출력 전 기록

사전 허용한 두 번째 후보는 접속 어미를 앞 절에 포함하도록 경계 계산을 수정한다.
동일 사례·기대 라벨·지표·허용 기준은 바꾸지 않는다. 전국 잠금 회귀는 후보 동결 후 한 번 진행한다.
사용하지 않는 v2 문맥 함수를 제거하고 Unicode casefold 길이 변화의 원문 위치 매핑을 점검한다.
언급별 필드의 API 전파와 신고 충돌 시 행동 카드 보류를 별도 계약 테스트한다.
이후 추가 모델 후보는 만들지 않는다. 새 실패가 남으면 문서·후속 검수 대상으로 남긴다.

## 기존 수치와의 차이

과거 `official_national_incident_parser_locked_2026-08-01.json`의 81.5047%는
Resolver SHA `27e64582…`를 사용한 442건·관찰 가능 319라벨의 포함 언급 Recall이다.
이번 변경 전 기준선은 SHA `2696fa7f…`와 현재 Parser 코드로 82.4451%다.
둘의 artifact가 다르므로 차이를 이번 Parser 개선 성과로 계산하지 않는다.
현재 후보는 동일 `2696fa7f…`로 다시 실행한 이번 기준선과만 비교한다.
원본 고정 SHA는 둘 다 `a1ef8e4b…`이며 세부 값은 각 원본 보고서에서 확인한다.

## B2 동결 후 자원 경계 보완

4,000자 합성 반복 입력에서 727개 언급, 132,132개 충돌 쌍이 생겨 Parser JSON이
25,879,956 bytes가 되었다. 의미 분류·후보·기대 라벨은 바꾸지 않고 충돌 상세를
최대 64쌍으로 제한한다. 모든 원문 언급과 재확인 필요 여부는 보존하며,
상한 도달 필드를 반환한다. 전체 충돌이 열거됐다고 주장하지 않는다.
이는 세 번째 모델 탐색이 아니라 API 자원 상한 보완이다. 최종 코드로 회귀를 다시 실행한다.
상한 보완 후 동일 반복 입력의 언급 727개·재확인 유지, 상세 64쌍 이하,
Parser JSON 2MiB 이하를 확인한다. 네트워크·모든 입력의 속도 보장 기준은 아니다.

기존 STT 후단 감사는 내용과 무관한 hash 순서 지역별 최대 50건으로 고정했다.
서울·인천 표본은 참조 물질 분모가 0이므로 성공률을 계산하지 않는다.
광주 A_operational_baseline은 summary에 `small` 대신 기존 로컬 모델 snapshot 경로를
기록해 첫 metadata 검사가 중단됐다. 추론 결과를 보지 않고 해당 snapshot ID를
명시적으로 대조하는 CLI 인자를 추가한다. CPU/int8/baseline 검사를 유지한다.
